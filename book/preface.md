# Preface

I wanted a single book that could do three jobs. It should teach Python and machine learning from the very first line of code. It should guide me, step by step, when I use machine learning to analyse data in research. And it should be the book I open when my code refuses to run and I cannot work out why. This handbook is my attempt at that book.

## Who this book is for

- **Beginners** who have never programmed. Part I starts from zero, and every line of code is explained beside it.
- **Students and researchers** who want to use machine learning in a thesis, a paper or an assignment, and want to do it *properly*: honest validation, no data leakage, confidence intervals, reproducible code.
- **Intermediate and advanced practitioners** who want a dense, searchable reference for NumPy, pandas, visualization, scikit-learn and TensorFlow, and an encyclopedia of real error messages.

## What makes it different

**Every line is explained.** Code examples are laid out with each line of code on the left and what it does on the right. Nothing is left as "magic".

**Every output is real.** The book was generated by a program that ran every code example, in order, and inserted exactly what Python printed and drew. When an example is meant to fail, you see the genuine error message, with an explanation of how to fix it.

**It follows the research workflow.** Part VII is a complete protocol for ML-based research, from defining the question to writing the Methods section, run end to end on a real dataset.

**It is built for when you are stuck.** Part VIII and the search box are designed for the moment you are staring at a traceback: find the error message, read the cause, apply the fix.

## How the book is organised

The eight parts follow the order in which the skills build on each other: Python, NumPy, pandas, visualization, scikit-learn, TensorFlow and Keras, ML for research, and debugging. The appendices hold quick-reference sheets, a glossary, worked solutions to every exercise, and an index of definitions. "How to use this book", a few pages ahead, suggests a route for each kind of reader.

## A note on versions

Libraries evolve quickly. The examples were run with the versions listed on the copyright page, including pandas 3, whose Copy-on-Write behaviour changes a few long-standing habits; these places are flagged in the text. If something behaves differently on your machine, compare versions first.

I hope this book saves you many late nights, and that it helps you turn data into insight you can trust.

*Mahir Absar Khan*, 2026
